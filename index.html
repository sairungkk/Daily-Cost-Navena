1. System Overview

Navera Revenue & Cost Management Suite is a system for recording and analyzing daily revenue, cost, and statistics for each outlet within the hotel. The system is organized into four main sections, accessible from the sidebar menu on the left:

  • 📝 Data Entry — Daily data entry page (administrator access only)
  • 📊 Analytics Dashboard — Overview of revenue and cost with charts and tables
  • 🕒 Shift Analytics — Sales analysis broken down by time period (meal shift) for each outlet
  • 🍽️ Meal Analytics — Detailed revenue & cost breakdown by outlet, meal period, and category (Food, Beverage, Wine, Other)
All menu items are located in the dark sidebar on the left side of the screen. Click a menu name to switch to that page.

2. Logging In

The first time you open the website, a login screen is always shown. Enter the password only (no username is required), then click "Login" or press Enter.

PasswordAccess LevelPages Available
1234General Staff📊 Analytics Dashboard and 🕒 Shift Analytics only
The 📝 Data Entry page is reserved for administrators and requires a separate administrator password. Please contact your system administrator if you need access to Data Entry.
This password screen is a basic front-end safeguard designed to prevent general staff from accidentally opening the data-entry page. It is not a high-security authentication system and should not be relied upon as the sole protection for sensitive data.

Once logged in, the system remembers your session for as long as the browser tab or window stays open. If you close the browser and reopen it, you will need to log in again.

2.1 Logging Out

At the bottom of the left-hand sidebar there is a "🔒 Log Out" button. Click it to log out immediately and return to the login screen — useful when you are finished using the system or need to switch users.

3. Sidebar Navigation

The left-hand sidebar is made up of three parts, from top to bottom:

  • Logo and system name (NAVERA)
  • The four main menu items — click to switch pages. The active tab is highlighted with a gold bar.
  • The Log Out button, located at the very bottom of the sidebar
On mobile devices or narrow screens, the sidebar moves to a horizontal bar at the top of the screen for easier use.

4. Data Entry Page (Administrators Only)

This page is used to record daily revenue, cost, and statistics for each outlet. It is only accessible to users who have logged in with an administrator password.

4.2 Entering General Information

Before entering meal-level data, fill in the following basic fields first:

  • 📅 Date — the date the record applies to
  • 🍽️ Outlet — select the outlet (Reveira House, Junsai, Tapanyaki, Terrace, Juniper, Marcele, Canteen)
  • 📦 Direct Purchase (Food/Bev) / 📑 Store Issue (Food/Wine/Bev/Other) / 📥 Transfer In / 📤 Transfer Out / 💳 Cr Cost (OC) — เป็นค่าแยกตามหมวด Food, Bev, Wine, Other (THB)
  • ☀️ Weather — the weather condition for that day
  • 🛏️ Room Available / 🔑 Room Sold / 🏨 Com./HU. Room / 👥 Total Guests — room and guest statistics
If you select a date and outlet that already has a saved record, the system automatically loads the existing data into the form so it can be edited immediately.

4.3 When "Canteen" Is Selected

If the outlet is set to Canteen, the system shows an additional "Staff Canteen Entry" section for entering the total headcount and total cost. The system automatically calculates the target budget (60 THB per person) and the variance between actual cost and budget.

4.4 Entering Meal Data (Meal Entry Table)

For regular outlets, enter data separately for five meal periods: ABF, Breakfast, Lunch, Dinner, and Supper — each split into Food, Beverage, Wine, and Other. Each row accepts Revenue, Cover, and Cost.

When a Revenue value is entered in any row, the system automatically checks the corresponding Category checkbox.

You can press Tab or Enter to move to the next field for faster continuous entry (Shift+Enter to move back).

4.5 Saving Data

Once all required fields are filled in, click "✨ Save Data to System" at the bottom of the form to save the record.

5. Analytics Dashboard Page

Displays an overview of business performance with charts and tables. Accessible to both general staff and administrators.

5.1 Cost Mode Toggle & Filter Bar

  • 🏷️ Raw Meal Cost / Allocated Net Cost — toggle buttons at the top of the page switch every cost figure, chart, and table on this page between the two cost definitions. Allocated Net Cost (default) = Direct Purchase + Store Issue + Transfer In − Transfer Out − Cr Cost; Raw Meal Cost = the meal-level costs entered in Data Entry.
  • 📅 Date Range — select a date range, or click "Today" to view today's data instantly
  • 🍽️ Outlet — view a single outlet, or select "All Outlets" for combined data

5.2 KPI Summary Cards

Total Revenue, Avg Check, Total Net Cost (or Total Raw Meal Cost), Total Purchase, Total Issue, Total Cr Cost/OC, Gross Profit, food/beverage cost ratios, room occupancy, room-sold, guest counts, and weather. All cost figures follow the cost mode selected with the Raw / Allocated toggle at the top of the page.

5.3 Charts and Tables

  • 📊 Revenue & Cost Comparison by Outlet
  • 🍩 Revenue Share by Category
  • 📈 Daily Revenue & Cost Trend
  • 📋 Outlet Summary Breakdown
  • 🍔 Food Summary Breakdown / 🍷 Beverage Summary Breakdown / 🍾 Wine Summary Breakdown / 🍽️ Other Summary Breakdown

Click "🔄 Refresh" to reload the latest data, or "🔄 Refresh Excel" to pull fresh data from the source Excel file.

6. Shift Analytics Page

Analyze sales broken down by time period (shift/meal) for each outlet. Accessible to both general staff and administrators.

  • Raw Meal Cost / Allocated Net Cost — switch the cost calculation mode
  • 📅 Date Range — select the range to analyze, or click "Today"
  • 📋 Performance summary table by outlet and meal period
  • 📊 Chart comparing revenue by meal period across outlets

Click "🔄 Refresh Shift Data" to load the latest data.

7. Meal Analytics Page

A detailed breakdown of revenue and cost for each outlet, meal period (ABF, Breakfast, Lunch, Dinner, Supper), and category (Food, Beverage, Wine, Other). Each outlet has its own subtotal row, and a Grand Total row summarizes all outlets at the bottom. Accessible to both general staff and administrators.

  • 📅 Date Range — select the range to analyze, or click "Today"
  • 🏷️ Raw Meal Cost (Unallocated) — badge showing that meal-level costs are displayed as raw, unallocated figures

Click "🔄 Refresh Meal Data" to load the latest data.

8. Frequently Asked Questions

I forgot the password. What should I do?

Passwords are set by the system administrator. If you forget yours, please contact the administrator to have it reissued.

I logged in with 1234 but can't see the Data Entry menu — why?

This is expected. The password 1234 is a general staff password, designed only to view data through the Dashboard and Shift Analytics pages. Contact your administrator if you need to record or edit data.

I'm logged in, but reopening the browser asks for the password again.

The system only remembers your login for as long as the current browser tab or window stays open, for security. Closing and reopening the browser requires logging in again.
